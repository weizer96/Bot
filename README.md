# 🤖 Автоклимат Бот

Telegram-бот для записи клиентов в автосалон "Автоклимат". Поддерживает выбор услуги, даты и времени, сбор контактных данных и отправку заявки администратору.

## 📦 Функции

- Приветственное сообщение с кнопкой "Записаться"
- Выбор одной из 6 услуг
- Ввод даты и времени записи (по правилам рабочего графика)
- Сбор ФИО и телефона
- Отправка заявки администратору Telegram

## 🚀 Запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корне и добавьте:
```
BOT_TOKEN=your_telegram_bot_token
ADMIN_CHAT_ID=your_admin_chat_id
```

3. Запустите бота:
```bash
python bot.py
```
